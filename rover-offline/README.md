# ROVER ONE 本地离线网页

这个入口只构建小车遥控页面，不包含仓储台、信号实验室或任何 CDN 资源。构建结果是普通
`index.html + assets` 静态站，安装到香橙派后由 nginx 在 `http://10.42.0.1` 提供；手机只需
连接 `ROVER-ONE` 热点，不需要外网，也不需要在香橙派上安装 Node.js。

## 构建

在仓库根目录运行：

```powershell
npm run build:rover-offline
```

输出位于 `rover-offline/dist/`。生成完整交付 ZIP 请运行根目录的：

```powershell
.\build-rover-offline-package.ps1
```

或双击 `生成小车离线包.cmd`。

仅在当前电脑预览时，可双击根目录的 `启动本地遥控网页.cmd`，保持命令窗口开启并访问
`http://127.0.0.1:3001/`。这个地址固定进入演示模式；实车仍使用香橙派的 `http://10.42.0.1`。

## 为什么不能双击 index.html 控车

正式控制页必须由香橙派通过 HTTP 提供。浏览器直接打开 `file://` 文件时会发送
`Origin: null`，网关会按安全设计拒绝；放行这个来源会让任意本地网页都有机会尝试连接小车。
同源入口还能确保页面自动使用 `/ws`，无需手填设备地址。

## 运行约束

- 页面没有远程字体、图片、脚本、分析服务或 API 请求。
- 不使用 Service Worker，避免旧控制页缓存与新版网关协议不一致。
- 页面打开或重连后始终保持锁定，必须人工长按启用控制。
- 切后台、失焦、关闭页面和断链都会尝试归零；真正的停车保障仍由网关 200 ms 和 STM32
  300 ms 独立看门狗完成。
